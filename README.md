# 🏥 Hệ Thống Quản Lý Phòng Khám (Clinic Management System)

Dự án Fullstack quản lý phòng khám toàn diện, hỗ trợ thanh toán trực tuyến, quản lý lịch hẹn và thông báo realtime.

## 🚀 Tech Stack
- **Backend:** Java 21, Spring Boot, Spring Security (JWT), MySQL, Hibernate.
- **Frontend:** ReactJS, TailwindCSS, Vite.
- **Mobile App:** Flutter (Dart).
- **Bên thứ 3:** VNPay (Thanh toán), Firebase Cloud Messaging (Push Notifications), Cloudinary (Lưu trữ ảnh).

## ✨ Tính Năng Nổi Bật
- Phân quyền (RBAC) cho 5 roles: Admin, Lễ tân, Bác sĩ, Kỹ thuật viên, Bệnh nhân.
- Đặt lịch hẹn online, nhắc lịch tự động qua App (FCM).
- Thanh toán qua cổng VNPay (Sandbox & Production).
- Quản lý kho thuốc, cảnh báo thuốc sắp hết hạn.
- Gửi thông báo realtime qua WebSocket (STOMP).
